# Firebase Storage Upload

React file upload practice project with Firebase Storage configuration.

## Project structure

- `firebase-storage/src/components/UploadFile.jsx`
- `firebase-storage/src/firebase.js`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/firebase-storage.git
cd firebase-storage
```

Enter `firebase-storage` before installing dependencies. Configure Firebase Storage access rules and use non-sensitive test files.

Install Node.js and npm, then run `npm install` and `npm run dev` in the application directory. Open the terminal URL.
